🐝 Welcome to Purple Bee!

I'm your task assistant. I can help you create and manage tasks right here in chat. Here's how everything works.

━━━━━━━━━━━━━━━━━━━━

📋 THE MAIN MENU

Whenever you message me, I show three options:

1. Create a Task
2. Delete a Task
3. Purple Bee Rules

Just reply with the number (like "1") or the name.

━━━━━━━━━━━━━━━━━━━━

✅ HOW TO CREATE A TASK

Reply "1", then follow along:

1. Pick a project — I'll list your projects, reply with a number.
2. Pick or create — I'll show tasks already in that project. Reply with a number to add details to one, OR type a brand-new task title to create one.
3. Subtasks — add smaller steps if you like, or skip.
4. Description — tell me what the task is about.
5. Status — To Do, In Progress, or Review.
6. Priority — Low, Medium, High, or Urgent.
7. Due date — type it as YYYY-MM-DD (e.g. 2026-07-20). It must be today or later.
8. Estimated hours — roughly how long it'll take.
9. Tags — add a few, or reply "Skip".

That's it — I'll confirm with a link to your new task. 🎉

━━━━━━━━━━━━━━━━━━━━

🗑️ HOW TO DELETE A TASK

Reply "2", then:

1. I'll list tasks that are still To Do or In Progress.
2. Reply with the number of the one to remove.
3. Tell me the reason (this is kept for our records).
4. Done — it's deleted.

━━━━━━━━━━━━━━━━━━━━

💡 GOOD TO KNOW

• You can type "cancel" any time to stop and start over.
• Every task remembers which channel it came from — WhatsApp, Telegram, or the app.
• If you're a linked user, your tasks are saved to your account automatically.
• Not linked yet? Open Purple Bee → Settings → Connect Telegram.

━━━━━━━━━━━━━━━━━━━━

📜 THE HOUSE RULES

1. Every task belongs to a project.
2. Tasks in Review should be checked before they're marked complete.
3. Overdue tasks get flagged at the next team sync.
4. Deleting a task always needs a reason.
5. "Urgent" is only for things blocking a release or client deadline.

Ready when you are — just say "Create a Task" to begin! 🐝
