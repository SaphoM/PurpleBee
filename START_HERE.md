## 📞 Help Section

### Common Issues

**"Node.js not found"**
→ Install from https://nodejs.org/

**"PostgreSQL not found"**
→ Install from https://www.postgresql.org/download/

**"npm install fails"**
→ Check internet connection, then try again

**"Port in use"**
→ Change PORT in backend/.env

**"Database error"**
→ Check DATABASE_URL in backend/.env
